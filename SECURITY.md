# Security

This is a local command launcher, not a sandbox. Review scripts and imported operations before approving them. Do not place passwords or API keys directly in sample configurations, screenshots, issue reports or logs.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/EJYDOvO/StratagemDesk-/security/advisories/new). Include the affected version, platform, impact and reproduction steps. Do not post credentials, user configurations or exploit details in a public issue. Skip reproduction steps that could expose real users' data.

The public-readiness checks scan Git history and distribution contents for common secret and privacy indicators, verify original artwork hashes, and test workflow safety boundaries. These checks do not prove that arbitrary configured commands or third-party binaries are safe.
